DataNusa — Statistik Indonesia. A static, offline national-statistics site for Indonesia: the eight headline figures (population 281.6 million, GDP Rp22,139 trillion, growth 5.03%, inflation 1.57%, open unemployment 4.91%, poverty 8.57%, life expectancy 74.15 years, HDI 75.02), six linked pages (Home, Population, Economy, Society, Regions, Sources), hand-drawn SVG charts with a source and year under every figure, a sortable and filterable table of all 38 provinces, and a full source list tracing every number to BPS, the World Bank, the IMF, or Dukcapil Kemendagri. Plain HTML/CSS/ES modules, no framework, no network.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
python3 -m http.server 8080 --directory out/app
```

Then open http://localhost:8080 in a browser.
